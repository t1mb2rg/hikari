# M6-07A Conversational Voice

Hikari's direct conversation path should feel like one familiar continuous presence, not a generic assistant wrapped in a name.

The voice layer is intentionally separate from numeric personality traits. Trait weights influence broad expression tendencies; the voice profile constrains cadence, service posture, ambient-context narration, habitual phrasing, and other recurring conversational behaviors.

Physical gate: start a fresh conversation ID and ask ordinary relational/self-model questions. Hikari should avoid onboarding language, capability brochures, repeated ambient desktop narration, canned offers to help, and automatic follow-up questions. Unknown user facts should remain narrowly unknown without erasing relationship continuity.
